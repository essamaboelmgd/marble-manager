# إدارة الرخام

تطبيق سطح مكتب محلي لإدارة نشاط بيع وتركيب الرخام، مبني باستخدام Electron وReact وSQLite.

## التشغيل والتطوير

```bash
npm install
npm test
npm run lint
npm run build
npm run dev
```

يتم إعادة بناء `better-sqlite3` تلقائيًا على ABI المناسب عند تشغيل الاختبارات أو Electron. لا يحتاج المستخدم النهائي إلى Node أو MongoDB أو سيرفر.

التقارير تدعم الطباعة العادية A4 والطباعة الحرارية 80mm، ويمكن تفعيل PIN اختياري من الإعدادات لحماية التشغيل على الجهاز.

## إنشاء نسخة Windows

```bash
npm run dist:win
```

ينتج البرنامج ملف NSIS داخل مجلد `dist/`، والبيانات أثناء التشغيل تُحفظ في مجلد بيانات Electron المحلي. النسخ الاحتياطي يتم من داخل التطبيق ويمكن حفظه في مجلد يختاره المستخدم.

## الاختبارات

اختبارات domain تغطي المعاملات الذرية للمشتريات والمبيعات والدفعات والمصروفات والإلغاء، بالإضافة إلى تدوير آخر ثلاث نسخ احتياطية تلقائية.
